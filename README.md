# Mami

Mami is a personal AI day manager. You talk to it on Telegram; it plans your day as time
blocks, logs what you did and spent, coaches you against your targets, reads your
WHOOP recovery, and shows everything in a calm web app. One FastAPI backend,
Postgres as the single source of truth, Claude as the only AI.

Architecture and decisions: see the "Personal AI Day Manager — Architecture
Review & Plan" doc.

## What works

**Telegram**
- Messy messages ("45 min DSA, £12 lunch, skipped gym, groceries tomorrow")
  become separate activities, expenses, tasks and ideas, saved immediately.
- Every reply ends with a receipt of what was really saved, plus "undo".
- Corrections ("actually only 30 minutes") update the record in place, with
  before/after kept in the audit history.
- Changes to plans, commitments, goals and targets, and deletions, come as
  proposals with Approve and Reject buttons, run once, and are refused if the
  record changed meanwhile.
- Long-term memory: what you state is confirmed; the assistant's own
  inferences are only observations until you confirm them.
- `/whoop` connects WHOOP; `/help` shows examples. Voice notes get a nudge to
  use keyboard dictation (Claude reads text and images, not audio).

**Scheduled, with quiet hours, a daily cap and cooldowns**
- Morning brief at 07:30: fresh WHOOP recovery, a proposed plan, top priorities.
- Reminders at task due times.
- Evening check-in at 21:30: at most 3 questions about important blocks, and only if needed.
- Day close at 04:05: unreported blocks become "Not reported" (never "Skipped"),
  and the day is saved with stats and a short summary, even with zero messages.
- Weekly review on Sunday at 19:00: measured progress against your targets, coaching,
  and proposals for changes.
- WHOOP sync five times a day: recovery, HRV, resting HR, sleep, strain, steps
  and workouts.

**Web app** (served by the backend at `/`)
- Login with a 6-digit code sent to your Telegram.
- Today: approvals, colour-coded timeline with a sky band and a "now" line, block
  checklists and statuses, focus timer (Pomodoro), what happened, WHOOP, spending.
- Week (targets, time by day, spending), Tasks and ideas, Money, Goals,
  Me (memories, coaching style, quiet hours, AI budget, data export).

**Safety**: Telegram secret header and account allowlist, encrypted WHOOP
tokens, one-time OAuth state, hashed login codes and sessions, row-level
security on every table, optimistic locking, idempotent jobs and replies, and a
monthly AI cost cap.

## Project layout

```
backend/
  app/
    agent/        prompts, context builder, tools (read/auto/approval), agent loop
    integrations/ WHOOP OAuth + sync
    telegram/     webhook, ingest, outbound, client
    api.py        JSON API for the web app (+ Telegram-code login)
    approvals.py  run approved actions exactly once
    reviews.py    day close and evening check-in
    scheduler.py  creates daily jobs (idempotent)
    notify.py     quiet hours, caps, cooldowns
    jobs.py       durable Postgres job queue
    views.py      read models shared by the agent and the web app
    models.py     tables; alembic/ has the migrations
  tests/          58 tests against real Postgres, incl. all 15 spec scenarios
  web_dist/       built web app (generated by `npm run build` in web/)
web/              Next.js + TypeScript + Tailwind source
```

## Run it locally

Needs Python 3.12+, Postgres 16 and Node 20+.

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env              # fill in values
createdb daymanager && createdb daymanager_test
alembic upgrade head
pytest                            # 58 tests
uvicorn app.main:app --reload     # http://localhost:8000

cd ../web && npm install && npm run build   # rebuilds backend/web_dist
```

## Go live for free (about 15 minutes, £0 hosting)

1. **Telegram:** [@BotFather](https://t.me/BotFather) -> `/newbot` -> name it Mami, keep the token.
2. **Claude:** API key at platform.claude.com/settings/keys; set a monthly limit on the Billing page.
3. **Supabase (free):** new personal project -> Connect -> copy the connection
   string, change `postgresql://` to `postgresql+psycopg://`, insert your password.
4. **GitHub:** push this folder to a private repo.
5. **Render (free plan):** New -> Blueprint -> pick the repo. Fill in
   `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY` (WHOOP ones can wait).
   `TELEGRAM_WEBHOOK_SECRET`, `APP_ENCRYPTION_KEY` and `CRON_KEY` are generated by Render.
6. **Setup page:** copy `TELEGRAM_WEBHOOK_SECRET` from Render's Environment tab, then open
   `https://<your-app>.onrender.com/setup?key=<that secret>`. It sets the webhook,
   creates your profile, and gives you a one-tap "Connect my Telegram to Mami" link.
7. **Keep awake (free):** the setup page shows a `/cron/tick` URL. At cron-job.org,
   create a job that opens it every 5 minutes. This stops the free server sleeping, so
   reminders and check-ins arrive on time.
8. **WHOOP (optional):** at developer-dashboard.whoop.com create an app with the read
   scopes, redirect URL `https://<your-app>.onrender.com/whoop/callback`; put the client
   ID and secret in Render; send `/whoop` to Mami.
9. Open the app on your phone, log in with the Telegram code, Add to Home Screen.

Free-tier notes: Render's free web service sleeps after 15 minutes idle (the
cron ping prevents this; Render gives 750 free hours a month, enough for one
always-on service). Supabase Free pauses projects with a week of no activity
(daily use prevents this) and has no automatic backups.
